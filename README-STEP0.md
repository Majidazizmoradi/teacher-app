# مرحله ۰ - زیرساخت امن (شاخه phase1-storage)

این مرحله **هیچ تغییری در رفتار برنامه نمی‌دهد**. فقط این‌ها را فراهم می‌کند:
- ساخت APK آزمایشی با شناسه جدا (`com.daftarclass.app.dev`) که **کنار برنامه فعلی نصب می‌شود و به اطلاعاتش دست نمی‌زند**.
- یک کلید امضای ثابت، تا نسخه‌های آزمایشی روی هم نصب شوند (بدون حذف و از دست رفتن اطلاعات).
- ۵۶ آزمون خودکار که نتیجه محاسبات (میانگین، مستمر، رتبه، فهرست نمرات، تقویم و ...) را با نسخه v1.0 مقایسه می‌کنند. اگر محاسبه‌ای خراب شود، ساخت APK متوقف می‌شود.

## ساختار پوشه‌ها در مخزن (بعد از آپلود باید دقیقاً این‌طور باشد)
```
.github/workflows/build-apk.yml
assets/            (آیکون‌ها)
ci/debug.keystore
tests/             (آزمون‌ها، داده آزمایشی و نتیجه طلایی)
www/index.html
www/native.js
www/fonts/README-FONT.txt
.gitignore
capacitor.config.json
package.json
README-STEP0.md
```

## قبل از آپلود (فقط یک بار)
1. در GitHub بالای صفحه (Code) شاخه را روی **phase1-storage** بگذارید. اگر ساخته نشده، منوی شاخه ← نام را تایپ کنید ← Create branch.
2. شاخه **main** را دست نزنید.

## روش الف: با Git (پیشنهادی، روی کامپیوتر)
zip را در یک پوشه باز کنید. در پوشه مخزن (teacher-app) این دستورها را بزنید:
```
git fetch origin
git checkout phase1-storage
```
محتوای zip را داخل پوشه مخزن کپی کنید (روی فایل‌های هم‌نام جایگزین شود)، بعد:
```
git add -A
git status
git commit -m "Step 0: dev build, fixed key, golden tests"
git push origin phase1-storage
```

## روش ب: با سایت GitHub (بدون Git)
1. مطمئن شوید بالای صفحه شاخه **phase1-storage** است.
2. **Add file ← Upload files**.
3. zip را روی کامپیوتر باز کنید و **خود پوشه‌ها و فایل‌ها** را (نه فایل zip) داخل صفحه بکشید. پوشه‌های `.github`، `assets`، `ci`، `tests`، `www` و فایل‌های بیرونی همه باید باشند.
4. پایین صفحه گزینه **Commit directly to the phase1-storage branch** را بگذارید (نه Create a new branch) و Commit بزنید.
5. وارد پوشه‌ها شوید و ساختار بالا را با چشم کنترل کنید (مخصوصاً `.github/workflows/build-apk.yml` و `ci/debug.keystore`).

## بعد از آپلود
1. تب **Actions** ← اجرای تازه «Build APK» (خودکار شروع می‌شود).
2. اول کار **test** باید سبز شود (۵۶ آزمون). بعد **build** (حدود ۵ تا ۱۰ دقیقه).
3. وارد همان اجرا شوید ← پایین صفحه **Artifacts** ← `app-debug-dev-<شماره>` را دانلود کنید و zip را باز کنید.

## آزمایش روی گوشی
- [ ] APK را نصب کنید. برنامه‌ای با آیکون **نارنجی** و نام «دفتر کلاس (آزمایشی)» ساخته می‌شود.
- [ ] برنامه اصلی شما با آیکون آبی هنوز هست و **اطلاعاتش سالم است** (بازش کنید و ببینید).
- [ ] برنامه آزمایشی بدون اینترنت باز می‌شود (حالت هواپیما).
- [ ] یک کلاس و چند دانش‌آموز بسازید و یک امتحان ثبت کنید؛ بخش گزارش و لیست نمرات را باز کنید. ظاهر و نتیجه مثل برنامه اصلی است.
- [ ] یک بار دیگر Build را اجرا کنید (Actions ← Build APK ← Run workflow ← شاخه phase1-storage) و APK دوم را **روی APK اول** نصب کنید. نباید «App not installed» بدهد و اطلاعات باید بماند.

## اگر مشکل پیش آمد
- **test قرمز شد:** وارد اجرا شوید، متن خطا را بفرستید.
- **build قرمز شد:** قدم قرمز را باز کنید و عکس یا متنش را بفرستید.
- **در نصب «App not installed»:** معمولاً برنامه آزمایشی قبلی با کلید دیگری نصب شده؛ فقط همان برنامه آزمایشی (نارنجی) را حذف کنید، نه برنامه اصلی را.
- **فونت:** فایل Vazirmatn.woff2 در `www/fonts` نیست و برنامه با فونت ساده نمایش داده می‌شود؛ مشکلی نیست.

## بازگشت (اگر پشیمان شدید)
شاخه phase1-storage را حذف کنید. چیزی در main و برنامه فعلی شما تغییر نکرده است.
